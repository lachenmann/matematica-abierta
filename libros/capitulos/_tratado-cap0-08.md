## 0.8. Resumen de notación {#sec-ta-0-8}

Las decisiones activas de notación introducidas en este capítulo son:

| símbolo / forma | significado adoptado | decisión normativa |
|---|---|---|
| $x\in A$ | pertenencia | símbolo primitivo de la teoría de conjuntos |
| $A\subseteq B$ | inclusión no estricta | $\subset$ no se usará ambiguamente para inclusión propia |
| $A\subsetneq B$ | inclusión propia | requiere $A\subseteq B$ y $A\ne B$ |
| $\{x\in A:P(x)\}$ | separación restringida | prohibido omitir el conjunto ambiente sin justificación |
| $\varnothing$ | conjunto vacío | sólo después de la Proposición 0.2.5 |
| $\{a,b\}$, $\{a\}$ | par no ordenado, singleton | reservadas llaves para conjuntos |
| $A\cup B$ | unión | estándar |
| $A\cap B$ | intersección | estándar |
| $A\setminus B$ | diferencia de conjuntos | se descarta $A-B$ para evitar colisión algebraica |
| $\mathcal P(A)$ | conjunto potencia | se descarta $2^A$ en la fase fundacional |
| $\langle a,b\rangle$ | par ordenado de Kuratowski | paréntesis $(a,b)$ quedarán disponibles para intervalos y tuplas informales posteriores |
| $A\times B$ | producto cartesiano | estándar |
| $aRb$ | $\langle a,b\rangle\in R$ | notación infija permitida cuando la relación lo aconseje |
| $\operatorname{dom}R$ | dominio de relación | se descarta $D(R)$ |
| $\operatorname{ran}R$ | recorrido de relación | $im$ se reserva para funciones/subconjuntos |
| $R^{-1}$ | relación inversa | no presupone funcionalidad |
| $S\circ R$ | composición: primero $R$, luego $S$ | lectura de derecha a izquierda |
| $[a]_\sim$ | clase de equivalencia | se admite $[a]$ sólo con relación inequívoca |
| $A/{\sim}$ | conjunto cociente | barras inclinadas sólo tras definir la equivalencia |
| $f:A\to B$ | función con dominio y codominio explícitos | el codominio forma parte de la identidad de $f$ |
| $f(a)$ | evaluación | reservada a elementos del dominio |
| $f[X]$ | imagen directa de subconjunto | corchetes distinguen imagen de evaluación |
| $f^{-1}[Y]$ | preimagen de subconjunto | no requiere que $f$ sea biyectiva |
| $f^{-1}$ | función inversa | sólo tras probar biyectividad |
| $B^A$ | conjunto de funciones $A\to B$ | dominio en el exponente |
| $(x_i)_{i\in I}$ | familia indexada | formalmente una función con dominio $I$ |
| $\leq$ | orden no estricto | relación primaria en la teoría del orden |
| $<$ | orden estricto asociado | definido por $a\le b$ y $a\ne b$ |
| $\sup S$, $\inf S$ | supremo, ínfimo | sólo cuando la existencia haya sido demostrada |
