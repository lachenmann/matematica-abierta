## 3.11. Notas bibliográficas {#sec-ta-3-11}

Este capítulo no importa ningún teorema externo; todas las demostraciones son internas al desarrollo del tratado.

- Landau sirve como contraste para la extensión de $\mathbb Z$ a $\mathbb Q$ y para la disciplina algebraica de las fracciones.
- Tao sirve como contraste para la construcción de racionales como clases de equivalencia, para las pruebas de buena definición y para la transición hacia completitud.
- Garling orienta la continuidad estructural entre cuerpos ordenados, propiedad arquimediana y análisis real.
- Conway permanece especialmente relevante para la próxima etapa de completitud y, más adelante, para la construcción de Dedekind.

Las demostraciones y la arquitectura local son propias. No se utiliza el axioma de elección.
