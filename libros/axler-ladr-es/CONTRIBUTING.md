# Cómo contribuir

Gracias por ayudar a mejorar esta edición española abierta de *Linear Algebra Done Right*.

## Vías de contribución

Usa un **Issue** para señalar una errata, discutir terminología o proponer una mejora antes de editar un pasaje complejo. Usa un **Pull Request** cuando puedas proponer un cambio concreto y verificable.

## Tipos de cambio

Indica una de estas etiquetas conceptuales en el título o descripción:

- `TRAD`: fidelidad, claridad o terminología de la traducción;
- `ERRATA`: discrepancia con la fuente, fórmula, referencia o error tipográfico;
- `SOL`: corrección o mejora de una solución propia;
- `NOTA`: ampliación pedagógica o matemática;
- `QA`: numeración, referencias, LaTeX, enlaces o formato.

## Qué debe incluir una propuesta

Cuando corresponda, incluye:

1. archivo y pasaje afectado;
2. ubicación en Axler 4e;
3. texto actual;
4. texto propuesto;
5. justificación matemática, lingüística o editorial;
6. fuente externa si la propuesta depende de una referencia adicional.

## Criterios de revisión

Una contribución se evalúa por:

- fidelidad al original;
- corrección matemática;
- consistencia terminológica;
- claridad del español;
- compatibilidad con la estructura del libro;
- compatibilidad de licencia.

La aceptación de un Pull Request no implica que una unidad quede automáticamente cerrada; el estado `CERRADO` requiere además el QA editorial completo del proyecto.

## Licencia de las contribuciones

Al enviar una contribución a este subproyecto, declaras que tienes derecho a aportarla y aceptas que se distribuya bajo **CC BY-NC 4.0**, salvo que se acuerde expresamente otra cosa compatible antes de su incorporación.

No copies soluciones, traducciones o comentarios de terceros que no puedan redistribuirse bajo estas condiciones.
