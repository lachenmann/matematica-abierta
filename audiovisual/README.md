# Audiovisual de Matemática Abierta

Este directorio contiene la capa audiovisual canónica de Matemática Abierta.

## Tres niveles

- **MA-VIZ**: visualización breve de una relación matemática concreta.
- **MA-EXP**: explicación de un concepto o argumento, compuesta por una o varias MA-VIZ.
- **MA-CLS**: clase completa asociada a una unidad del tratado.

El vídeo no sustituye al texto canónico. Cada pieza audiovisual declara de qué capítulo, sección, definición, proposición, teorema o ejercicio depende.

## Principio MA-M01

**No animar información: animar relaciones.**

El movimiento debe corresponder a una transformación matemática: refinamiento, aproximación, cambio de base, proyección, deformación, paso al límite, dependencia paramétrica o construcción de una demostración.

## Fuente y derivados

La fuente Manim es canónica para la animación. De ella se prevén derivados MP4/WebM y fotogramas estáticos reutilizables en la web y en los libros.

El primer prototipo es MA-CLS-C13-P01, para el capítulo visible 13 de Cálculo para matemáticos. Su fuente interna es T1-C14.md — Del área y las sumas a la integral.
