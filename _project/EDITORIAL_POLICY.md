# Política editorial de Matemática Abierta

Flujo de trabajo:

1. estudio privado;
2. comprensión;
3. reconstrucción;
4. reescritura;
5. registro de procedencia;
6. revisión;
7. publicación.

El repositorio público no almacena notas privadas ni transcripciones extensas de fuentes.

Todo problema publicado debe incluir una solución desarrollada.

El contenido textual original se publica bajo GNU FDL 1.3 o posterior.
